# Coming Attractions

Upcoming movie releases screen for a portrait 4K classroom display (OptiSigns).

Data from TMDB. The API key is NOT stored in this repo. Pass it in the address:

    https://mrwilliams-cit.github.io/coming-attractions/?key=YOUR_TMDB_KEY

Options: `&days=75` `&max=8` `&maxrating=PG-13` `&hide=id1,id2` `&rotate=12` `?demo=1`

This product uses the TMDB API but is not endorsed or certified by TMDB.
